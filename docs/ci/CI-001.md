## 更新与人工审查

`.github/dependabot.yml` 仅启用 `github-actions` 生态，根目录扫描，每周对 `main` 提交更新 PR，分配给本 fork 维护者。没有 groups，每个 Action 分开审查；不自动升级 Go、pnpm、Node、Python 或扫描工具。配置字段依据 [Dependabot options reference](https://docs.github.com/en/code-security/reference/supply-chain-security/dependabot-options-reference)，SHA 更新能力见 [GitHub 官方说明](https://docs.github.com/en/code-security/how-tos/secure-your-supply-chain/secure-your-dependencies/auto-update-actions)。

每次更新 Action SHA 必须在独立 PR 中记录官方 release notes 链接与审查结论，重新核对官方 tag/commit、同一行精确版本注释、输入兼容性、runner/Node 要求、凭据处理与受影响工作流。运行固定策略测试和 actionlint，取得控制面的独立复核后由维护者手动合并。涉及写权限、artifact、registry 登录、发布的 Action 禁止自动合并；普通 Action 更新也采用同一人工流程。

2026-10-11 只读查询确认仓库 `allow_auto_merge=false`，仓库中没有自动合并工作流；本任务没有改变仓库设置。Dependabot 配置本身不提供自动合并开关。若今后启用仓库自动合并或新增合并机器人，必须继续排除上述 Action 更新。CODEOWNERS 负责审查归属，不能代替分支保护；当日 `main` 保护查询为 HTTP 404，未声称保护或 required checks 已强制启用。
