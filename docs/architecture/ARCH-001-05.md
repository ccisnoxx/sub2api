## 所有权与提交边界

`responsesServiceObservationEmitter` 独立持有既有 server source、attempt token 和观测。构造时只调用源请求的 beginAttempt 一次，沿用同一匿名身份和 logical turn；不生成用户提供的身份，不操作计费、存储或队列。

`emitFrozenTerminal` 仅由分类器首次冻结成功分支调用。组件不增加第二套完成/取消/错误优先级，也不调用请求的最终冻结函数。缺失终态快照保存 unknown/terminal_missing，但不冻结分类器，后续真实终态仍可替换；重复快照保留首次观测时点。已初始化观测和 fallback 都交付 Clone 副本。

候选继续通过原源请求的 attempt 过滤上报，迟到旧 attempt 不能替换当前候选。请求最终 owner、失败原因归属、CommitServiceStatusObservation 和异步提交仍在原位置。组件在原 observer mutex 下使用，保留 observer→源 request 的锁顺序；不新增锁、goroutine 或 AfterFunc 生命周期。

计时观察器不再保存可变 UsageTiming DTO，快照由输出、用量、分类器及观测组件的独立副本组成。只有通过平台/起点校验的实际观察器产生 TimingVersion=1，nil/未采集入口仍返回原版本 0；所有公开字段、可空语义及内部观测的 JSON 隐藏规则保持。
